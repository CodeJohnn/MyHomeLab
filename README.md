# CodeJOHN • Home Lab 

Um laboratório virtual interativo da GuedesSEC, criado em 3D com Three.js. Explore o ambiente, interaja com o personagem e os NPCs e personalize a disposição dos móveis e a aparência dos cômodos.

## Recursos

- Navegação pelo laboratório e interação com objetos.
- Editor para mover e girar móveis, com salvamento automático no navegador.
- Personalização de paredes, pisos, iluminação e sons do ambiente.
- Conversas com NPCs e opções de voz em português.
- Monitores que podem exibir vídeos e sites.
- Quadros decorativos que aceitam imagens personalizadas.
- Interface adaptada para dispositivos móveis.

## Tecnologias

- HTML, CSS e JavaScript com módulos ES.
- Three.js 0.160.1 para renderização 3D.
- `localStorage` para guardar as preferências e o layout no navegador.

## Como executar

Abra `index.html` usando o Live Server do VS Code. O projeto carrega o Three.js por CDN, então é necessária conexão com a internet para iniciar a cena 3D.
